EIS Worker untuk Windows

1. Ekstrak seluruh isi ZIP ke folder tetap, misalnya D:\EIS-Worker. Jangan menjalankan dari dalam ZIP.
2. Pastikan Python 3.12 dengan Tcl/Tk terpasang dari python.org. Jalankan INSTALL.cmd sekali.
3. Pada launcher, klik Siapkan dependensi. Tunggu selesai; unduhan pertama dapat beberapa GB.
4. Pada website, daftarkan perangkat atau buat koneksi baru, lalu unduh file koneksi JSON.
5. Pada launcher, klik Impor koneksi dan pilih JSON tersebut. Periksa alamat API sebelum menyetujui.
6. Klik Jalankan worker pada website atau pada launcher. Biarkan jendela launcher terbuka.
7. Status Online di website menandakan worker sudah terhubung. Training dimulai dari halaman Eksperimen.

Saat sudah terpasang, website dapat membuka launcher melalui eisworker://. Browser mungkin meminta izin membuka aplikasi. Browser tidak dapat memasang/menyalakan program diam-diam.

Jika tombol website tidak membuka apa pun (misalnya browser tertanam tidak mendukung protokol), jalankan BUKA-LAUNCHER.cmd atau INSTALL.cmd dari folder ini.

INSTALL mendaftarkan penghubung hanya pada akun Windows saat ini, tanpa admin. Folder tidak boleh dipindah setelah pemasangan. Untuk melepas penghubung, buka UNINSTALL-LAUNCHER.py dengan Python; ini tidak menghapus data.

Koneksi dan hasil tetap berada dalam folder worker ini. Jangan membagikan worker.json. Paket unduhan tidak menyertakan token, data training pengguna, atau lingkungan Python laptop pembuat.

IDENTIFIKASI BURUNG WAV / MP3 — MODEL SEMENTARA
1. Hentikan worker sebelum mengganti model atau menyiapkan dependensi.
2. Klik Impor ZIP model burung dan pilih sumatra_model_inference_package.zip dari Syafiq.
3. Klik Siapkan model burung (CPU). Environment BirdNET/TensorFlow terpisah dari PyTorch. Perlu internet dan ruang disk beberapa GB. Gunakan folder pendek agar instalasi Windows berhasil.
4. Setelah status model siap, jalankan worker kembali. Website menampilkan model sementara siap setelah heartbeat terbaru.
5. Unggah WAV PCM atau MP3 pada menu Identifikasi suara. Batas prototipe 700 MiB dan 2 jam. Biarkan laptop menyala.
6. Hasil memuat waktu, spesies, confidence, dan sumber skor. Beberapa spesies dapat terdeteksi bersamaan.
7. Tidak ada deteksi dibedakan dari unknown. Confidence adalah skor model, bukan persentase akurasi. Model belum final.
8. Unduh XLSX dari website. Jika hasil dibagi beberapa bagian, unduh seluruh bagiannya.

Model dan rekaman tidak masuk paket worker unduhan. Model diimpor lokal, belum diunduh otomatis dari layanan cloud. Jangan membagikan worker.json atau direktori hasil berisi data sensitif.
Training model burung belum tersedia dalam paket ini; halaman Eksperimen tetap merupakan demo training digits.
Hasil simulasi lama tetap ditandai SIMULASI dan bukan prediksi model.
